# Patient Management System

A full-stack Patient Management System built using Angular and ASP.NET Core Web API.

## Technologies

- Angular
- TypeScript
- ASP.NET Core Web API
- C#
- Entity Framework Core
- SQL Server
- JWT Authentication
- HTML
- CSS

## Features

- User Login
- JWT Authentication
- Authorization
- Angular Route Guard
- Logout
- Patient Create
- Patient List
- Patient Update
- Patient Delete
- REST API Integration
- SQL Server Database
- Entity Framework Core
- Angular Forms
- Angular Services
- Angular Routing
- HTTP Interceptor

## CRUD Operations

The application supports:

- Create Patient
- View Patients
- Edit Patient
- Delete Patient

## Authentication

JWT authentication is used to secure patient-related API requests and Angular routes.

## Architecture

Angular Frontend
        ↓
ASP.NET Core Web API
        ↓
Entity Framework Core
        ↓
SQL Server
